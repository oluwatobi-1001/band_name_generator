# Band Name Generator

A simple Python command-line program that generates a fun band name based on the city you grew up in and your pet's name — inspired by the classic "band name" trick.

## How It Works

The program asks two questions:
1. What city did you grow up in?
2. What's your pet's name?

It then combines your answers to suggest a band name.

Example:
Welcome to the band name generator
What's the city you grew up in? Lagos
What's your pet's name? Max
Your band name could be Lagos Max

## How to Run It

### Option 1: Run the Python script
Make sure you have Python installed, then run:
python "band_name generator.py"

### Option 2: Run the standalone executable
No Python installation needed — just download the .exe file (see Releases) and double-click it.

## Requirements

- Python 3.x (only needed if running the .py file directly)
